# Haptic Armbands

These armbands were developed by me as part of the 5th semester project, *Pain reduction for children using VR and haptic feedback as distraction*, which explores the use of virtual reality and haptic feedback to reduce pain during blood sampling procedures.

The armbands provide vibrotactile feedback through multiple vibration motors positioned around the user's arm. By delivering tactile stimulation close to the site of the medical procedure, the system aims to support pain reduction while also increasing immersion within the VR experience.

The design is based on the Pain Gate Theory, which suggests that non-painful sensory stimuli, such as vibrations, can interfere with the transmission of pain signals and reduce perceived pain. To utilize this effect, the armbands generate synchronized vibration patterns during key moments in the VR experience.

The armbands communicate with the VR application through Unity and can be controlled independently, allowing different vibration patterns, intensities, and timing sequences to be applied to each arm. This enables the system to provide contextual feedback that matches events occurring in the virtual environment.

For further information about the project, read the report [here](docs/P5_MED5___Pain_reduction_for_children_using_VR_and_haptic_feedback_as_distraction.pdf) (See appendix [here](https://github.com/user-attachments/files/28747053/P5___MED5_Appendix.pdf)).
